# Cryptographic concepts

This section contains short reference documents describing the cryptographic concepts that appear throughout the experiments.

The goal is not to provide a complete cryptography course, but to explain the minimum background required to understand the OpenSSL implementation of post-quantum cryptography.

## Available concepts

- ASN.1
- DER
- PEM
- Object Identifiers (OID)
- PKCS#8
- SubjectPublicKeyInfo (SPKI)
- Providers
